# Nanhee — Portfolio

UI 엔지니어로의 전환을 준비하며 만든 개인 포트폴리오 사이트입니다.

## 소개
TV App 퍼블리셔로 5년, 디지털 사이니지 4년 — 여러 플랫폼과 제약 안에서 쌓아온 경험을,
Figma로 직접 기획하고 Next.js로 코드까지 완성했습니다.

## 라이브 사이트
https://nh-portfolio-three.vercel.app

## 주요 프로젝트
- TV App 멀티클라이언트 플랫폼
- 솔루션 홍보 홈페이지 (Responsive Web)
- 키오스크 멀티디바이스 설계 (DID)
- Ui-system-guide (Design System)

## 기술 스택
- Next.js (App Router), React, Tailwind CSS v4
- 다크모드 토글, AOS 스크롤 애니메이션
- Vercel 배포

## 디자인 프로세스
Figma에서 컬러·타이포 디자인 토큰(Variables, Text Styles)을 먼저 정의하고,
컴포넌트 단위로 설계한 뒤 Next.js로 옮겨 구현했습니다.
